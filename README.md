# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Muskanateeq/50-Plus-Python-Assignments-and-Projects.git
```

Navigate into the project

```bash
cd 50-Plus-Python-Assignments-and-Projects
```

Run any assignment

```bash
python filename.py
```

If a project has dependencies

```bash
pip install -r requirements.txt
```
